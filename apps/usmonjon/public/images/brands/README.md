# Brand files

Payment systems that have no simple-icons entry. Drop the file here and
point `icon` at the path in `src/content/skills.ts`:

    payme.svg   -> icon: "/images/brands/payme.svg"
    click.svg   -> icon: "/images/brands/click.svg"
    atmos.svg   -> icon: "/images/brands/atmos.svg"

SVG preferred; a transparent PNG at 128x128 or larger also works.
Visa comes from simple-icons and needs no file.
